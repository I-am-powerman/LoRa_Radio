# LoRa Messenger

Автономный мессенджер для связи в горах без интернета и сотовой сети.
Два устройства общаются по радио через LoRa, каждое раздаёт WiFi и показывает веб-интерфейс на телефоне.

---

## Железо

| Устройство | Роль |
|---|---|
| Raspberry Pi Pico W | Первый узел связи |
| ESP32-S3 Zero | Второй узел связи |
| LoRa RA-01 (SX1278) × 2 | Радиосвязь 433 МГц |

---

## Архитектура

```
Ты                                      Друг
────────────────────────────────────────────────
[Телефон]                           [Телефон]
    │ WiFi                               │ WiFi
[Pico W]  ←────── LoRa 433MHz ──────→ [ESP32-S3]
 AP Mode                                AP Mode
192.168.4.1                          192.168.4.1
```

Каждый носит своё устройство в кармане. Телефон подключается к нему по WiFi, открывает браузер на `192.168.4.1` — и пишет сообщения. Сообщения летят по радио через LoRa.

---

## Из чего состоит проект

### 1. LoRa слой — передача данных
Модуль RA-01 на чипе SX1278 подключается по SPI. Отвечает за отправку и приём сообщений между двумя устройствами.

- Инициализация SX1278 через SPI
- Отправка строки через `println`
- Проверка входящего пакета через `receivedPacket`
- RSSI — уровень сигнала (важно в горах, чтобы знать насколько далеко друг от друга)

### 2. WiFi слой — точка доступа
Каждое устройство работает в режиме AP (точка доступа) — само раздаёт WiFi, не зависит от внешних роутеров.

- Модуль `network`, режим `AP_IF`
- Имя сети, пароль, шифрование WPA2
- IP адрес точки доступа: `192.168.4.1`

### 3. Веб сервер — интерфейс
Сервер на чистом `socket` + `asyncio`. Отдаёт HTML страницу и обрабатывает запросы от браузера.

Три маршрута:
- `GET /` — отдать HTML страницу мессенджера
- `POST /send` — принять сообщение от пользователя
- `GET /messages` — отдать список сообщений в формате JSON

### 4. Хранение сообщений
Простой список в памяти. Хранит текст, время и отправителя каждого сообщения. Сбрасывается при перезагрузке устройства.

### 5. Главный цикл — конкурентность
Устройство делает два дела одновременно:
- Слушает LoRa — вдруг пришло сообщение от друга
- Обслуживает HTTP запросы от браузера

Реализовано через `asyncio` — две независимые задачи работают в одном потоке без блокировок.

## Запуск

Загрузи все файлы на устройство через Thonny, запусти `main.py`.
Подключись телефоном к WiFi сети устройства, открой браузер на `http://192.168.4.1`.

> **Для ноутбука:** если страница не открывается при подключённом интернете —
> отключи прокси в настройках системы.
> Linux: `gsettings set org.gnome.system.proxy mode 'none'`
> Windows: Настройки → Сеть → Прокси → отключить
> Mac: Системные настройки → Сеть → Прокси → снять галочки
